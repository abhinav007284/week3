2 — Create the GitHub Maven project (commands to run locally)

For a simple webapp Maven project:

# create a simple Maven webapp (non-interactive)
mvn archetype:generate \
  -DgroupId=com.example \
  -DartifactId=exam-webapp \
  -DarchetypeArtifactId=maven-archetype-webapp \
  -DinteractiveMode=false

cd exam-webapp
git init
git add .
git commit -m "initial maven webapp"
# Create repo on GitHub (via web UI) then push:
git remote add origin https://github.com/<your-username>/<repo>.git
git branch -M main
git push -u origin main


For a normal (non-web) Maven Java project:

mvn archetype:generate \
  -DgroupId=com.example \
  -DartifactId=exam-java \
  -DarchetypeArtifactId=maven-archetype-quickstart \
  -DinteractiveMode=false


What to show the examiner: GitHub repo page with pom.xml and a simple src folder.

4 — Example: Declarative Pipeline — 2-stage (Jenkinsfile)

Create a Jenkinsfile at the repo root. This is a 2-stage declarative pipeline: Build and Test.

pipeline {
  agent any
  tools { maven 'Maven 3' } // name you configured in Jenkins global tools
  stages {
    stage('Build') {
      steps {
        echo "Running mvn clean package"
        sh 'mvn -B -DskipTests=false clean package'
        archiveArtifacts artifacts: 'target/*.jar', fingerprint: true
      }
    }
    stage('Test') {
      steps {
        echo "Running mvn test"
        sh 'mvn test'
        junit 'target/surefire-reports/*.xml'
      }
    }
  }
  post {
    always { echo "Pipeline finished" }
  }
}


Notes:

agent any runs on any available node.

Use sh on Linux/macOS and bat on Windows.

archiveArtifacts keeps build artefacts for the job page.

junit publishes test results.

What to show the examiner: commit with Jenkinsfile and a successful build console output.

5 — Example: Declarative Pipeline — 3-stage

Add a third stage, e.g., Integration/Test or Deploy.

pipeline {
  agent any
  tools { maven 'Maven 3' }
  stages {
    stage('Build') {
      steps { sh 'mvn -B -DskipTests=false clean package' }
    }
    stage('Unit Test') {
      steps {
        sh 'mvn -B test'
        junit 'target/surefire-reports/*.xml'
      }
    }
    stage('Static Analysis & Archive') {
      steps {
        // optional: run static analysis (spotbugs/spotless) or simply archive
        sh 'echo "Static checks (placeholder)"'
        archiveArtifacts artifacts: 'target/*.jar', fingerprint: true
      }
    }
  }
  post {
    success { echo "Build succeeded" }
    failure { echo "Build failed" }
  }
}


Exam tip: explain each stage’s purpose — Build compiles, Unit Test runs tests, final stage archives and runs checks.

6 — Scripted Pipeline example (Jenkinsfile)

Scripted pipelines use more imperative Groovy. Good to show examiner you understand both styles.

node {
  def mvnHome = tool 'Maven 3'
  stage('Checkout') {
    checkout scm
  }
  try {
    stage('Build') {
      sh "${mvnHome}/bin/mvn -B -DskipTests=false clean package"
      archiveArtifacts artifacts: 'target/*.jar'
    }
    stage('Test') {
      sh "${mvnHome}/bin/mvn test"
      junit 'target/surefire-reports/*.xml'
    }
    stage('Publish') {
      echo "Publish steps (e.g., push to Nexus) - placeholder"
    }
  } catch (err) {
    currentBuild.result = 'FAILED'
    throw err
  } finally {
    echo "Cleaning up workspace"
    cleanWs()
  }
}
